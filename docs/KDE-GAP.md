# Win10DE vs KDE Plasma 差距分析（KDE-GAP）

> 生成日期：2026-08（功能补全三批 15 项完成后）。
> 对照基准：[KDE Plasma 6](https://kde.org/zh-cn/plasma-desktop/)（KWin + Plasma 外壳 +
> System Settings 六大类模块 + KDE 应用生态）+ [System Settings 模块文档](https://docs.kde.org/trunk_kf6/en/systemsettings/systemsettings/modules.html)。
> 本文档只列**差距**（已实现功能见 README「状态」节），按类别分优先级，供后续功能补全
> 立项使用。

---

## A. 窗口管理（KWin 层）

| 功能 | KDE 对应 | Win10DE 现状 | 优先级 |
|---|---|---|---|
| Snap 布局选择器（2×2 / 3×3 网格） | KWin 平铺辅助 | 仅 Win+←/→/↑/↓ 半屏/全屏，无布局网格弹窗 | 高 |
| 窗口规则（按类/标题强制位置/大小/装饰） | KWin 窗口规则 | 无 | 中 |
| 桌面特效（模糊、滑入、最小化动画、Present Windows） | KWin 特效 | 仅窗口移动/阴影动画 | 中 |
| 概览模式（缩放网格/任务视图） | Overview | 无 | 中 |
| 多显示器图形化排列 | 显示器设置拖拽排列 | 有 D-Bus SetPosition 但无拖拽 GUI | 中 |
| 分数缩放 | KWin 分数缩放 | 仅整数 scale | 中 |
| Night Light 护眼色温 | KWin Night Light | 无 | 中 |
| HDR / ICC 色彩管理 | KWin 色彩管理 | 无 | 低 |
| 快捷键 GUI 编辑器 | 快捷键 KCM | 配置化（[shortcuts] 段）但无 GUI | 低 |
| KWin 脚本/扩展 | KWin scripting | 无 | 低 |
| 全局菜单（应用菜单进面板） | Global Menu | 无 | 低 |
| 边缘触发动作（拖拽到屏缘动作） | 边缘 KCM | 无 | 低 |

## B. 桌面与外壳

| 功能 | KDE 对应 | Win10DE 现状 | 优先级 |
|---|---|---|---|
| 桌面小部件系统（时钟/天气/监控挂件） | Plasmoids | 无 | 中 |
| 桌面右键菜单完善（排列图标/新建/终端） | 桌面菜单 | 仅有双击打开 | 中 |
| 多面板/面板编辑模式 | Plasma 面板编辑 | 单任务栏 | 低 |
| 工作区切换器小部件/预览 | Pager | 仅 Win+1..4 快捷键 | 低 |
| 桌面文件夹视图模式/网格 | Folder View | 仅有图标列表 | 低 |

## C. 系统设置缺失模块（对照 KDE 六大类）

**已覆盖**：外观（主题/壁纸）、系统（关于/自启）、显示、电源、音频、默认应用、网络、蓝牙。
**缺失**：

| 类别 | 缺失模块 | 优先级 |
|---|---|---|
| 外观 | 字体、图标主题、光标主题、窗口装饰选择、屏幕保护 | 中 |
| 工作区行为 | **屏幕锁定（密码验证，PAM）**、桌面特效配置 GUI、启动/关机行为、边缘 | 高（锁定） |
| 硬件 | **输入设备（鼠标/键盘/触摸板/游戏手柄）**、打印机、相机、可移动存储/自动挂载、GPU 信息、绘图板、屏幕亮度/色彩 | 中 |
| 系统 | **日期时间**、区域/语言（locale）、用户账户管理、系统通知规则、会话管理 | 中 |
| 网络 | 代理、防火墙、远程桌面、VPN | 低 |
| 其他 | 在线账户、软件源 | 低 |

## D. 系统应用缺失

| 应用 | KDE 对应 | Win10DE 现状 | 优先级 |
|---|---|---|---|
| **软件中心**（Flatpak/包管理 GUI） | Discover | 无 | 高 |
| **进程管理器**（进程树/终止进程） | KSystemMonitor 进程页 | 系统监视器仅性能页 | 高 |
| **文本编辑器** | Kate / 记事本 | 无 | 中 |
| **PDF/文档查看器** | Okular | 无 | 中 |
| **图像查看器** | Gwenview | 无 | 中 |
| **压缩/归档工具** | Ark | 无 | 中 |
| **回收站窗口**（恢复/清空） | Dolphin 回收站 | 删除进回收站但无 UI | 中 |
| **屏幕录制** | Spectacle 录屏 / wf-recorder | 仅截图（w10screenshot），无录屏 | 中 |
| **科学/进制计算器** | KCalc 科学模式 | 仅标准模式 | 低 |
| 邮件/PIM、KDE Connect | KMail/Kontact、KDE Connect | 无（体量大） | 低 |

**文件管理器（w10explorer）差距**：标签页、拆分视图、KIO 网络位置（FTP/SMB/SSH）、
全文搜索、服务菜单/插件、压缩集成。
**终端（w10term）差距**：分屏/标签页、滚动搜索、配色方案、配置档案。

## E. 系统集成/服务

| 功能 | KDE 对应 | Win10DE 现状 | 优先级 |
|---|---|---|---|
| **文件索引/全文搜索** | Baloo | 开始菜单搜索仅扫文件名，无索引 | 高 |
| **每应用音量控制** | Plasma 音频（per-app） | 仅总音量/设备 | 中 |
| **GTK 应用主题联动** | Breeze GTK | Qt 应用有主题，GTK 无 | 中 |
| 通知规则（按应用） | 系统通知 KCM | 全局通知，无规则 | 低 |
| 自动挂载/移动存储 | Solid / KIO | 无 | 低 |
| 密码管理 | KWallet | 无 | 低 |
| 剪贴板增强（钉住/动作） | Klipper | 有历史+图片，无钉住（Plasma 6.5 已加） | 低 |
| 登录管理器 | SDDM | w10-session 无登录管理器 | 低 |
| 自动深浅色切换 | Plasma 6.5 新特性 | 无 | 低 |

## 优先级建议

- **高优先（日常核心体验缺口）**：
  1. 软件中心（Discover 等价）
  2. 进程管理器（补全系统监视器：进程树/终止）
  3. Snap 布局选择器（2×2/3×3 网格）
  4. 锁屏密码验证（PAM）
  5. 文件索引搜索（Baloo 等价）
- **中优先（常用生产力）**：输入设备设置、文本/PDF/图像查看器、回收站 UI、
  每应用音量、多显示器排列 GUI、窗口规则、桌面小部件
- **低优先（锦上添花）**：KWin 特效/脚本、Night Light、全局菜单、KWallet、
  登录管理器等
